# 可访问性、双语与视觉审计

审计以“信息和操作不能依赖单一感官、指针或语言长度”为基础。自动检查由 `src/accessibility.test.tsx`、组件测试和完整前端测试执行。

本轮另在本地 WebView 尺寸下目视检查了英文与简体中文的深色界面：工具栏关键动作、双窗格标题、路径输入、状态栏均未截断，活动窗格除描边外同时显示文字标记。

| 项目             | 结果 | 落实方式                                                                            |
| ---------------- | ---- | ----------------------------------------------------------------------------------- |
| 键盘焦点         | 通过 | 标准 Tab 不再被劫持；Control-Tab 切换活动窗格；焦点环全局可见                       |
| 核心文件操作     | 通过 | 选择、打开、复制、移动、剪切/粘贴、重命名、新建文件夹、废纸篓及冲突决策均有键盘路径 |
| 窗格尺寸         | 通过 | 分隔条可聚焦，左右方向键调整，暴露数值和百分比文本                                  |
| 活动窗格         | 通过 | 同时使用边框和“Active/活动”文字，不只依赖颜色                                       |
| 错误             | 通过 | `role=alert`、警告符号和明确文本同时存在                                            |
| 长列表           | 通过 | grid 暴露总行数、活动后代、选中状态；仅渲染可见窗口                                 |
| 对话框           | 通过 | 冲突、诊断、粘贴和操作对话框都有可访问名称；Escape 可关闭可取消流程                 |
| 动效             | 通过 | `prefers-reduced-motion` 时停止不确定进度动画                                       |
| 对比度           | 通过 | 主/次/辅助文字在浅深表面均 >= WCAG AA 4.5:1；浅色辅助文字已加深                     |
| 200% 缩放/窄窗口 | 通过 | 移除根节点固定最小尺寸；680px 以下收起非核心侧栏，操作工具栏可横向访问              |
| 中英文           | 通过 | 自动验证键集合完全一致且非空；关键动作保持完整文字，不使用截断                      |
| 浅色/深色/高对比 | 通过 | 系统主题令牌；forced-colors 为活动、焦点和拖放目标提供系统轮廓                      |

人工视觉复核清单：在 macOS 浅色、深色和“增强对比度”下各检查一次 100%/200% 缩放；用最长的冲突说明、恢复提示和中文任务状态确认按钮文字完整；使用 VoiceOver 从工具栏依次进入左右窗格、列表、任务抽屉和冲突对话框。发现关键动作被裁切或焦点不可见即视为验收失败。
