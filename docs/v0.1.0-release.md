## 安装

1. 打开 DMG。
2. 将 `PaneDeck.app` 拖入 `Applications`。
3. 首次启动若被 Gatekeeper 拦截，右键 `PaneDeck.app` → **打开**，或到“系统设置 → 隐私与安全性”允许打开。

## 签名与公证

- 使用 **ad-hoc 签名**，未使用 Apple Developer ID，未公证。
- `spctl --assess` 会拒绝；这不代表应用损坏，用户需首次手动允许。
- 因此当前 DMG 适合本地/受控分发，不适合不经说明的公开下载。

## 卸载

启动应用后使用 **PaneDeck → 卸载 PaneDeck…**，确认删除应用数据并将应用移到废纸篓。详见 [uninstall.md](uninstall.md)。

直接拖 app 到废纸篓不会清理应用数据。

## 已知边界

- 完全磁盘访问等系统权限需在系统设置中手动移除；
- 访达共享收藏在无完全磁盘访问时隐藏并提示；
- 外接盘/云盘、macOS 14～16、原生单击/双击交互、重启恢复未全部实机验收；
- 当前为本地测试版，不在 GitHub 发布，不含自动更新。
