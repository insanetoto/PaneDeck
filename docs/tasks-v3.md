### PD-201 用产品图标替换窗格名称

- 状态：已完成（图标替换、窗格语义、语言及浏览器审查通过）
- 依赖：PD-200
- 目标：顶部不再显示左/右窗格文字，两侧使用 PaneDeck 图标。
- 交付：复用品牌资源生成/引用小尺寸 UI 资源；替换 `.pane-side-label`；调整导航区对齐及可访问语义。
- 验收：两侧可见文字移除、图标清晰且无重复品牌标题；左右区域名称仍可被辅助技术和测试定位；图标不增加无意义 Tab 焦点或未知点击行为；原有窗格切换和操作来源不变。

### PD-202 实现无外侧间隔的双窗格布局

- 状态：已完成（贴边布局、1px 分隔线、拖动和键盘调整验证通过）
- 依赖：PD-201
- 目标：工作区贴边，中央保留可调节的细分隔线。
- 交付：移除 shell 留白、窗格卡片圆角/阴影；修正列宽计算；实现透明分隔条命中区；保留内部控件间距。
- 验收：800×520、普通窗口和最大化时四周无外侧留白、中央无 9px 空白带；无横向溢出或状态栏截断；鼠标/键盘调整宽度正常，分隔条不拦截文件选择/拖放；标题栏、焦点、模态和底部反馈正常。

### PD-203 统一访达式树列表图标与字号

- 状态：已完成（代码/自动/浏览器验收通过；同机访达截图对照按用户决定暂缓）
- 依赖：PD-202
- 目标：让文件列表密度、字体和图标更符合 macOS。
- 交付：系统字体、字体/行高/图标/缩进令牌，统一文件夹和文档图标，调整展开箭头及元数据基线，同步虚拟列表行高计算。
- 验收：与同一机器访达列表进行截图对照并记录最终数值；浅深主题下名称、图标、选择、剪切和拖放状态可读；展开与进入分离；10,000 行 DOM 有界且滚动不重叠/跳位；深层长名称及 200% 布局缩放必要动作可达。

- 目标：确认视觉优化没有回退文件管理流程。
- 交付：新增相关组件/集成回归，v3 人工视觉清单，中英文及浅深主题记录，目录新建和 iCloud 删除问题复测记录。
- 验收：图标、贴边、树视觉三项有证据；复制/移动、同/跨窗格拖放、Option 复制、右键、创建子目录、冲突、日志、底部进度正常；自动质量门通过；缺少实机条件的项明确未测，不自行宣告通过。v2 中断/VoiceOver 和 GUI 性能专项仍按用户要求暂缓。

### PD-212 建立版本同步及发布前校验

- 状态：待开始
- 依赖：PD-211

- 验收：正常测试版本可通过；版本不一致、无效标签、非发布基线提交、重复公开版本均在上传前失败；建议 `v0.3.0-beta.1` 的 SemVer 和 macOS 包版本兼容；产物能追溯到标签和完整 commit SHA。

### PD-213 自动发布 GitHub Pre-release

- 状态：待开始
- 依赖：PD-210、PD-211、PD-212
- 目标：一次标签推送完成检查、打包和测试版下载发布。
- 交付：`.github/workflows/release.yml`；可信版本标签触发、质量门、打包、SHA-256、资产上传及发布；发布步骤限定 `contents: write`；使用内置 `GITHUB_TOKEN`。
- 验收：一次真实测试标签产生 `.app.zip`、`.dmg` 和 `SHA256SUMS.txt`；下载后校验一致；资产齐全才公开，标记 prerelease 且不成为正式 latest；普通提交不发布；测试/打包/上传失败不出现宣称可用的空版本；重跑不覆盖已公开资产，不使用强制推送修复标签。

### PD-214 验证安装、失败重试与发布文档

- 状态：待开始

- 验收：从实际 GitHub Release 下载 ZIP/DMG并在 Apple Silicon 复核包结构、启动及关键操作；记录未公证限制和 macOS 用户确认方式，不要求全局关闭安全功能；演练校验失败/无写权限/重复版本及失败草稿重试；缺少真实运行或安装证据时保持待验收。
