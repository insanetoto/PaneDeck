# PaneDeck v2 功能规划

> 状态：功能规划，尚未开始实现
> 基线：现有 v1 MVP；v2 是交互优化版本
> 开发方式：无日期、无工期；按依赖领取任务，验收通过后更新状态

## 1. 版本目标

让双窗格成为主界面，采用接近 macOS 访达的列表浏览和右键操作方式。移除品牌介绍、顶部操作栏、活动窗格标识和右侧任务抽屉；普通操作记录本地日志，持续执行的复制/移动在底部提供必要的进度和取消入口。

本版本沿用 Rust 安全操作引擎、任务队列、冲突决策、系统废纸篓、诊断脱敏和崩溃恢复能力。隐藏任务管理界面不等于移除后台任务机制。

## 3. 主窗口与操作来源

```text
系统窗口标题栏（保留）
双窗格工作区
├── 左窗格：导航 + 位置侧栏 + 可展开文件列表 + 目录状态
├── 可拖动分隔条
└── 右窗格：导航 + 位置侧栏 + 可展开文件列表 + 目录状态
底部反馈区（仅操作持续执行、失败或需要用户处理时出现）
冲突、名称输入、粘贴确认和恢复对话框（按需出现）
macOS 菜单栏：文件动作、视图、语言设置、诊断导出
```

- 应用内不再展示图标、产品描述、全局操作按钮、活动窗格文案或任务入口；删除相应空白占位。
- 各窗格的前进/后退、上级、路径输入、面包屑、隐藏项和排序继续可用。
- 内部仍记录最近获得焦点的窗格。快捷键使用该窗格；右键动作使用菜单打开时捕获的窗格和条目；拖放使用拖动来源及实际落点。提交请求后不因焦点变化改变操作对象。
- 两侧可保留各自选择，不用整窗格边框表达活动状态。标准控件焦点轮廓、选中文件高亮和拖放目标高亮继续保留。
- 标准 Tab 遍历控件，Control-Tab 切换窗格焦点；原有复制、移动、剪贴板等快捷键继续可用。输入路径或文件名时不能误触文件操作。
- 被移除的语言、诊断和核心操作入口通过系统菜单及上下文菜单提供，不新增另一条应用内顶部工具栏。

## 4. 访达列表式目录树

### 展开与导航

- 文件夹名称前显示展开箭头；点击箭头仅展开/折叠，不改变当前根目录、路径栏或历史。
- 点击行选择条目；双击目录或 Command-Down 进入目录并形成正常导航历史。保留 v1 的 Enter 进入目录行为，重命名仍使用 F2 或菜单，避免同时绑定 Enter。
- 子项按层级缩进，保留名称、大小、类型、修改时间列。排序只改变同一父目录的子项顺序，不将不同层级全局混排。
- 每个目录首次展开时按需读取；提供局部加载、空目录、无权限、目录消失和重试状态。单个子目录失败不清空整个窗格。
- 左右键分别折叠/回到父项、展开/进入第一子项；上下键按当前可见顺序移动焦点。目录树提供可访问层级、展开状态和名称。

### 状态、性能与安全

- 展开状态和树节点请求按窗格独立管理。每个树节点有自己的请求标识和取消逻辑，不能复用当前“每窗格一个读取器”而让并行展开互相取消。
- 所有节点仍使用 Rust 持有的原生路径与不透明引用。嵌套条目写操作必须解析所属目录会话，不接受前端拼接路径。
- 树节点会话需要明确持有与释放规则，避免当前最多 128 个浏览会话的淘汰机制使仍显示的子项立即失效；不得通过无限扩大缓存解决。
- 选择以条目引用表示，展开或排序不改变操作对象。折叠时移除不可见后代的选择，后代焦点回到折叠目录，避免隐藏选中项被误操作。
- 同时选择父目录和后代时，提交批量操作前去除被父目录覆盖的后代，避免重复复制、移动或删除；后端再次验证。
- 目录快捷方式/符号链接保留已有进入语义，v2 不提供内联递归展开，防止链接环无限展开。
- 外部变化刷新根目录及当前展开节点；合并事件、取消旧请求并释放监听。删除/断开目录时清理失效后代，并显示可解释错误。
- 只虚拟化当前可见树行；不预扫描整棵目录树。10,000 个可见条目时 DOM 行数保持有界；折叠、导航和卸载后释放读取与监听资源。

## 5. 右键菜单与拖放

### 右键菜单

优先采用 Tauri 原生上下文菜单，在外壳层映射菜单动作，文件规则继续留在 Rust 应用服务。若原生实现无法满足可访问性或动态菜单要求，必须先记录具体限制，再采用可验证的替代实现。

| 上下文   | 菜单内容                                                                                                          |
| -------- | ----------------------------------------------------------------------------------------------------------------- |
| 单个文件 | 复制到另一窗格、移动到另一窗格；复制、剪切；重命名；移至废纸篓                                                    |
| 单个目录 | 进入目录、展开/折叠、新建文件夹（创建在该目录内）；复制到另一窗格、移动到另一窗格；复制、剪切；重命名；移至废纸篓 |
| 多个条目 | 复制到另一窗格、移动到另一窗格；复制、剪切；移至废纸篓；不提供单项重命名                                          |
| 列表空白 | 在当前根目录粘贴、新建文件夹；刷新、隐藏项开关                                                                    |

- 分组之间使用分隔线，动作显示快捷键，不可用动作禁用；不出现 v2 未实现的预览、共享、标签或压缩菜单。
- 右键未选中项时先选中该项；右键已选中项时保持当前多选集合。空白菜单不能误用上次选中的文件作为作用对象。
- 目录行菜单中的“进入”和“新建文件夹”指该行目录，无需先进入或展开，确认框说明创建位置。空白菜单中的粘贴、新建指当前根目录；菜单栏及 Command-Shift-N 的新建仍作用于当前目录。目录行的新建不展示该快捷键，避免混淆目标。复制/移动到另一窗格必须在菜单或确认中明确目标目录。
- Escape、点击外部、菜单动作执行和导航变化后关闭菜单；靠近窗口边缘时保持可见；中文、英文和键盘操作均验收。

### 拖放

- 本版本范围为 PaneDeck 内部：跨窗格、同窗格文件拖入子目录、树形列表中跨层级多选拖放。与 Finder 等外部应用的双向拖放不在本次范围。
- 默认移动，按住 Option 复制，沿用 v1 语义；跨卷默认移动仍使用安全跨卷协议。该约定是 PaneDeck 产品决策，不声称完全复制 Finder 的卷间默认动作。
- 从已选中条目拖动时使用完整选择；从未选中条目拖动时仅拖动该项。拖动载荷使用不透明引用及本次拖动标识。
- 窗格空白表示当前根目录，目录行表示该目录；普通文件不是目标。落点提供高亮、动作提示和拒绝状态。
- 支持靠近列表上下边缘自动滚动；悬停折叠目录 700 ms 后展开，离开或取消时清除计时器。自动展开不是移动提交。
- 源自身、原父目录无效移动、源后代、只读目录、失效会话和不可用卷不得写入；前端提示与后端预检共同保证。
- 同名冲突继续调用现有冲突对话框；不因拖动省略确认或覆盖检查。

## 6. 操作日志与底部反馈

### 日志

- 所有文件写操作记录时间、关联标识、操作类型、检查点、逐项结果和结构化错误码；记录提交前拒绝、等待冲突、取消请求和最终结果。
- 使用稳定的逻辑操作关联标识连接批量冲突拆分及后续子任务，避免一批操作变成互不关联的日志碎片。
- 在应用数据目录保存版本化结构化日志。恢复日志与用于诊断的操作日志职责分开：恢复需要的原生路径只留本机恢复存储，公开诊断日志不包含完整路径、原始文件名或文件内容。
- 操作日志初始保留策略：单文件最多 10 MiB，最多 5 个轮转文件；属于可调整的实现默认值。未完成任务需要的恢复记录不能被普通日志轮转删除。
- 日志写入/同步失败必须产生可见的“操作日志未能保存”提示。已经提交的文件结果如实报告，不为日志失败反向删除或重做文件。
- 本版本不建设任务历史侧栏或独立日志浏览器；用户通过系统菜单主动导出脱敏诊断日志。

### 底部进度

- 建议默认：复制/移动提交后持续 500 ms 仍未结束才显示进度，避免短任务闪烁；不依赖必须先算出文件总大小，大目录扫描和跨卷校验阶段也能显示。
- 展示动作、条目数量、阶段、已处理量和可用时的速度。总字节数明确且大于零才显示百分比；未知总量显示不定进度，禁止除零、NaN 和虚假百分比。
- 跨卷移动区分准备、复制、校验、源清理、完成；复制字节达到 100% 时不得提前显示整个移动完成。
- 排队显示“等待”；取消先显示“正在取消”，仅收到取消终态后显示“已取消”。后端明确不可取消的提交阶段禁用取消并说明原因。
- 同时存在多个传输时使用底部紧凑列表：最多两张卡片可见，其余在底部区域滚动；不能占据右窗格或恢复完整任务历史。
- 成功卡片 2 秒后收起，所有结果仍写日志。失败、部分失败和“已复制但源未删除”提示保持至用户关闭，并提供错误摘要及诊断导出入口。
- 普通短任务成功不弹任务面板；短任务失败和预检拒绝立即在底部显示简短可解释提示，不能只有日志而让用户误以为成功。
- 冲突使用独立对话框；移除抽屉后仍须自动提示需要决策的操作。取消、恢复、诊断和剪贴板确认入口不依赖抽屉。

上述 500 ms、700 ms、2 秒和日志容量是本规划提出的初始默认值，验收固定验证，后续可依据实机体验调整。

## 7. 安全边界与非目标

- 文件操作继续经过不可变计划、执行前重验和统一队列；跨卷校验后才删除源；删除只进入系统废纸篓。
- v1 的中英文、浅深主题、无遥测、本地个人使用及 macOS 14+/Apple Silicon 边界延续。
- 不增加云盘、远程协议、批量重命名、预览、压缩、插件、永久删除、通用撤销、签名分发或跨平台支持。
- 不新增全盘目录索引、不实现 Finder 分栏视图、不在侧栏递归展示完整文件系统。
- v2 规则覆盖 v1 中有关顶部工具栏、活动标识、任务抽屉和平面列表的要求；其余安全规则继续有效。v1 文档保留为历史基线。

## 8. 核心验收场景

1. 启动后无应用顶栏、品牌描述、活动徽标和右侧任务抽屉；两侧导航和分隔条可用。
2. 左右独立展开三级目录，折叠不改变根路径，排序保留层级；权限失败和目录消失只影响相关分支。
3. 右键单项、多项、未选中项和空白区域，动作对象、菜单分组、禁用状态与快捷键正确。
4. 单项及多项拖到另一窗格、同窗格子目录和展开目录；Option 复制，自身/后代拒绝，同名冲突明确。
5. 短操作不弹任务界面但留下日志；失败可见；日志导出不泄露路径或内容。
6. 模拟超过 500 ms 的复制/跨卷移动，底部进度真实，校验阶段不冒充完成，取消和部分失败可解释。
7. 树形目录达到 10,000 个可见条目时虚拟化有效；导航、折叠和关闭后资源释放。
8. 中英文、浅深主题、200% 缩放、键盘、VoiceOver 和实际 macOS 右键/拖放人工验收；临时目录之外不执行破坏性测试。
