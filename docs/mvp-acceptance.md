# PaneDeck MVP 验收手册

本手册是 PD-044 的可重复验收入口。自动测试只写入测试创建的临时目录；真实废纸篓、外接卷拔出和 VoiceOver 属于明确列出的 macOS 人工复核，不在自动测试中操作用户文件。

## 一键验收

```bash
npm install
npm run test:e2e
npm run check
npm run benchmark
npm run build
```

成功标准：所有命令退出码为 0，最终可执行文件位于 `target/release/panedeck`。`npm run build` 使用 `--no-bundle`，不会生成安装包、签名、公证或更新配置。

## macOS 人工检查表

仅在专门创建的测试目录和可安全拔出的测试卷上执行：

- [ ] 在 Apple Silicon、macOS 14 或更高版本运行 `npm run dev`，确认出现一个 PaneDeck 窗口。
- [ ] 左右窗格分别打开两个测试目录；前进、后退、上级目录、面包屑、隐藏项目和排序互不影响。
- [ ] 只使用鼠标完成复制、移动、剪切/粘贴、重命名、新建文件夹，并从任务抽屉核对最终结果。
- [ ] 只使用键盘完成同一流程：标准 Tab 遍历控件、Control-Tab 切换窗格、F5 复制、F6 移动、Command-X/C/V、F2 重命名、Command-Shift-N 新建文件夹、Command-Backspace 移至废纸篓。
- [ ] 制造同名文件，依次检查跳过、替换、保留两者和取消；默认焦点必须位于“跳过”，原目标未经确认不得变化。
- [ ] 将测试文件移至废纸篓，确认任务成功，并在 Finder 废纸篓中恢复它；不要使用真实个人文件。
- [ ] 复制测试大文件时打开任务抽屉，确认进度、吞吐、耗时、取消请求和取消完成状态可区分。
- [ ] 在专用外接测试卷复制期间安全推出卷，确认任务失败可解释、应用不崩溃、源文件仍存在。
- [ ] 强制结束一个使用测试数据的复制任务，重启后确认出现恢复提示，且不会自动续传或删除源文件。
- [ ] 在浅色、深色、增强对比度、200% 缩放和中英文下复核关键动作无截断，活动窗格与错误不只依赖颜色。
- [ ] 使用 VoiceOver 遍历工具栏、左右窗格、文件列表、任务抽屉和冲突对话框，确认控件名称与状态可理解。
- [ ] 使用 Instruments 按 `performance-report.md` 记录真实 WebView 冷启动与滚动 FPS。

任何静默成功、静默覆盖、来源不明的删除、源文件先于跨卷校验被删除，均应立即中止验收。

## 已知限制

- 仅支持 Apple Silicon 和 macOS 14+；Rust 核心保持平台边界，但 Windows/Linux 未验收。
- 仅供本地个人使用；没有安装包、代码签名、公证、自动更新或应用商店配置。
- 不包含账号、云同步、SFTP、遥测、商业化、插件、压缩包编辑、终端、预览和目录比较。
- 重命名一次只处理一个项目；批量重命名不在当前任务范围。
- 删除只进入 macOS 废纸篓；恢复由 Finder 完成，不提供应用内撤销或永久删除。
- 异常退出后只解释中断任务并允许确认清理安全临时项，不自动盲目续传。
- 外接卷在操作中断开会终止相关操作；重新连接后需要用户核对并重新发起。
- APFS 不允许创建任意非法 UTF-8 文件名；核心原生路径模型和 IPC 往返有自动测试，但此类名称无法在当前 APFS 上做真实创建测试。
- 完整 GUI 冷启动与 Core Animation FPS 依赖 Instruments 人工测量；自动基准覆盖核心启动代理、目录首批、虚拟滚动计算、复制吞吐与 RSS。
- 主动诊断导出需要用户输入绝对保存路径；不会自动上传，也不会覆盖已有文件。

## 本地运行说明

要求：Apple Silicon Mac、macOS 14+、Xcode Command Line Tools、Rust stable（含 rustfmt 与 clippy）、Node.js 22.12–22.x、npm 10.x。

1. 在仓库根目录运行 `npm install`。
2. 运行 `npm run dev` 启动开发窗口；开发数据只来自用户主动打开的本地目录。
3. 提交前运行 `npm run test:e2e` 和 `npm run check`。
4. 性能变更运行 `npm run benchmark`；固定数据生成在系统临时目录，不读取真实用户目录。
5. 运行 `npm run build` 生成本地 release 可执行文件。
6. 直接运行 `target/release/panedeck` 可进行本机检查；当前不提供分发包。
