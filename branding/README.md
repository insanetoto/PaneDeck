# PaneDeck 品牌图标

## 设计语义

- 左右两个面板代表双窗格浏览。
- 中央留白代表文件在两个窗格之间受控流转。
- 底部错层代表有序叠放的 `deck`，也让图标在小尺寸下保持独特轮廓。
- 深海军蓝底色与蓝青双色用于表达克制、可靠和清晰的工作工具气质。

## 文件

- `panedeck-app-icon-master.png`：生成式设计母版，1254 × 1254、RGBA。
- `../src-tauri/icons/icon.png`：供当前 Tauri 应用使用的 512 × 512、RGBA 版本。
- `../src-tauri/icons/icon.icns`：由 Tauri 图标工具从母版生成的 macOS 应用图标资源。

## 使用边界

这是产品图标的首版原创视觉方案，不等同于商标可注册性结论。在正式申请商标前，应完成目标国家或地区的图形近似检索，并由设计师将最终确认的几何结构重绘为 SVG/PDF 等矢量母版，再生成不同尺寸和颜色版本。未经检索前，不应对外宣称图形不存在近似商标。

## 生成提示词

> Use case: original brand identity and production-ready macOS application icon concept. Asset: one square master icon for PaneDeck, a local dual-pane file organizer. Do not render the product name. Create a distinctive geometric symbol communicating two independent panes, deliberate transfer between them, and an orderly layered deck. Center it inside a native-feeling macOS rounded-square tile with generous optical safe area. Build the mark from two upright panel forms that interlock around a narrow central negative-space passage; subtly stagger their lower edges to suggest a deck without depicting literal cards. Use original minimal vector-like geometry, a strong silhouette, consistent corner radii, deep graphite/navy background, cool cyan and teal solid tones, and optional off-white negative space. Avoid text, letters, monograms, literal arrows, folder/file glyphs, Finder face, Commander One resemblance, copied brand shapes, photographic texture, glassmorphism, excessive 3D, glossy highlights, busy shadows, mockup devices, borders, watermarks, and signatures.
